# Загрузка системы — GRUB, сброс пароля, LVM
1. При загрузке, в меню GRUB, нажать `e` на нужном пункте
2. Найти строку, которая начинается с `linux` (там прописан путь к ядру и параметры)
3. В конец строки дописать:
```
init=/bin/bash
```
4. Нажать `Ctrl+X` (или `F10`) — система загрузится не в обычном режиме,
   а сразу в bash-консоль с правами root, минуя запрос пароля вообще
5. Задать новый пароль:
```bash
passwd root
```
6. Перезагрузиться — можно заходить с новым паролем

### Способ 2 — через Recovery Mode

В GRUB выбрать пункт `Advanced options`, затем вариант `recovery mode`.
Дальше в меню recovery mode выбрать `root` (Drop to root shell prompt) —
это тоже даёт доступ к консоли с правами root без пароля, аналогично
первому способу, только через штатный, готовый интерфейс recovery mode
(не нужно вручную редактировать строку `linux`).
