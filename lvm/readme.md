## Инструкция по запуску

1. Разблокировать скрипт создания дисков (Windows блокирует скачанные .ps1):
   powershell -c "Unblock-File -Path .\create-disks.ps1"

2. Создать виртуальные диски (один раз):
   .\create-disks.ps1

3. Поднять стенд:
   vagrant up
